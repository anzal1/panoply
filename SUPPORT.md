# Getting help

## Ask a question or share an idea

Use [Discussions](https://github.com/anzal1/panoply/discussions). It is the right place for "how do I", "does
Panoply do", early ideas for a tool, and show and tell. Answers there help the next person too.

Before you ask, these pages answer most questions:

- [README](README.md) for what Panoply is and how to install it
- [docs/KNOWN-LIMITATIONS.md](docs/KNOWN-LIMITATIONS.md) for what the beta leaves out on purpose
- [docs/PRIVACY.md](docs/PRIVACY.md) for what stays on your device
- [CHANGELOG.md](CHANGELOG.md) for what changed in each version

## Report a bug

Open an [issue](https://github.com/anzal1/panoply/issues/new/choose) with the bug report form. A report we can
act on has:

- the tool you used and the steps, in order
- what you expected and what happened, with the exact error text
- your operating system and Panoply version (`panoply version` on the command line, or About in the app)
- a sample file, if it is safe to share publicly. If it is private, say its type and size and how it was made.

Please do not attach files that hold personal data. We would rather have a description than a passport scan.

## Propose a new tool or a change

- A whole new tool: the module proposal form.
- A change to an existing tool or the app: the feature request form.
- You want to build it yourself: read [CONTRIBUTING.md](CONTRIBUTING.md) first.

## Report a security problem

Do not open a public issue. Follow [SECURITY.md](SECURITY.md).

## What to expect

Panoply is a free, open-source project. There is no support contract and no guaranteed response time. Bugs with a sample file and clear steps get fixed first.
