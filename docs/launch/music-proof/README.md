What the pages show:

- Each track page carries the line "Free for use under the Pixabay Content License", the artist JayStacksBeats (148
  followers, a link to JayStacksBeats.com and a Spotify artist profile), no "Content ID Registered" badge and no
  "AI generated" label. Other tracks listed on the same page do carry the AI label's icon, so the label is shown when it applies.
- The license summary says, in its list of what users may do: "Use Content for free", "Use Content without having to attribute the
  author (although giving credit is always appreciated by our community!)", and "Modify or adapt Content into new works".
  Prohibited uses include selling or distributing the content on a standalone basis, so the track is never committed to this
  repo or posted on its own, only inside the finished film.
- Only the full Content License is legally binding. The summary says so itself. The full text is linked from the summary page.
